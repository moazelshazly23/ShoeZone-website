# ShoeZone

A responsive, multi-page footwear e-commerce frontend with product browsing and a client-side shopping experience.

[View live demo](https://moazelshazly23.github.io/ShoeZone-website/)

## Features

- Product catalog with category, brand, gender and price filters, plus sorting.
- Product details, new arrivals, best sellers and offers pages.
- Shopping cart and wishlist saved in the browser with `localStorage`.
- Responsive navigation and checkout, account and informational page layouts.

## Built with

HTML5, CSS3 and vanilla JavaScript, with Bootstrap 5.3, Bootstrap Icons and Google Fonts loaded from CDNs.

## Run locally

Clone or download the repository, then open `index.html` in a browser. No build step or package installation is required. A local server such as VS Code Live Server can also be used.

Internet access is needed for the CDN assets. This is a frontend demo, not a production store: it does not include a backend, real authentication or payment processing.
